# Evaluation / Promptfoo

This folder contains prompt evaluation assets for CivicOs.

Recommended structure:

- `tests/evaluation/promptfoo.yaml` — Promptfoo test configuration
- `tests/evaluation/prompts/` — Prompt templates and judge instructions
- `tests/evaluation/golden/` — golden examples for PII redaction, RAG relevance, hallucination tests
- `tests/evaluation/scripts/` — helper scripts for running promptfoo or preparing datasets
